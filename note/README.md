## 一条重要提醒：文档与实现可能不一致

早期 PRD / 架构文档里写的部分结论在开发过程中**被实测推翻**了。凡笔记与旧文档冲突，**以本目录为准**：

- ~~HTTP-FLV 兜底~~ → **MediaMTX 原生不支持 HTTP-FLV**（官方拒绝实现），默认降级目标是 **HLS**，FLV 需外部网关（见 [07 §7.5](./07-视频流接入.md)）。
- ~~高德 `mapStyle: 'amap://styles/satellite'`~~ → `satellite` 不在官方样式列表，必须用 `TileLayer.Satellite` 图层（见 [04 §4.3](./04-高德地图.md)）。


## 贯穿全项目的三条通用教训

1. **静默失败是本项目最大的敌人。** 高德样式、grid 子组件、Vue 模板解析、WS 订阅丢失——全都不报错。凡是"配了但没反应"，先假设它静默失败了，再去找可观测出口（见 [06](./06-调试方法论.md)）。
2. **"派生值回传给第三方组件"必然形成回环。** 组件在 prop 变化时又 emit 回调，回调里若不先比对再回写，就会自激振荡甚至卡死浏览器（见 [03](./03-前端框架与布局.md)）。
3. **改了代码 ≠ 生效。** 前端产物要 `cp` 进 `server/internal/web/dist` 再 `make build`，后端要重启，浏览器要**强刷**（SPA 不刷新就永远跑旧代码）。
